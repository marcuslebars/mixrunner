📌 STEP 1: INSTALL DEPENDENCIES (Required - First Time Only!)
═══════════════════════════════════════════════════════════════

Open Terminal and run these commands:

   cd "/c/Users/marcu/Desktop/chance studio"
   pip install -r requirements.txt

Wait ~5 minutes for installation to complete.

───────────────────────────────────────────────────────────────

📌 STEP 2: LAUNCH MIXRUNNER
═══════════════════════════════════════════════════════════════

After dependencies are installed:

   EASIEST:   Double-click "LAUNCH_GUI.bat"

   OR:        Run "python run_gui.py" in Terminal

───────────────────────────────────────────────────────────────

📌 STEP 3: USE MIXRUNNER
═══════════════════════════════════════════════════════════════

1. Open Logic Pro with your project
2. Click "Connect to Logic Pro"
3. Click "Full Workflow"
4. Done! ✅

═══════════════════════════════════════════════════════════════

⚠️  IMPORTANT: You MUST install dependencies first!

If you see errors like "No module named 'loguru'":
→ You forgot to run: pip install -r requirements.txt
